# Archived pm-agent skills

These skills are part of Mapleton Hill's general-purpose `pm-agent` plugin but
are out of scope for the AVH Contentful migration's Figma-to-tickets focus, so
they were moved here rather than deleted. To bring one back into active use,
move its folder back into `pm_agent/skills/` and reference it again from
`pm_agent/agents/pm-agent.md` and `pm_agent/README.md`.

- `feature-spec` — epic/feature → product spec + candidate story slices.
- `prioritize-backlog` — RICE/ICE/MoSCoW ranking of a ticket set into a
  Now/Next/Later roadmap.
- `draft-sow-doc` — client-facing SOW "Estimates and Documentation" attachment.
- `status-update` — client-facing delivery comms from shipped tickets.
- `actuals-report` — time-tracking export → actuals hours per ticket, split by
  role.
